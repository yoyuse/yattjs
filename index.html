yatt.js (Yet Another T-Code Trainer, JavaScript version) は、 漢字直接入力 T-Code などの復習に特化した練習プログラムです。 かつて存在した T-Code トレーナー yatt の仕様をもとに JavaScript で実装して Web ブラウザ上で動作するようにしたものです。

オリジナルの yatt は、 西岡真吾さんが作成し、田川典生さんがメンテナンスしていたツールで、 すでに覚えた文字を効率的に反復練習するための練習テキストを生成する C 言語プログラムです。 田川典生さんのページで入手できる tserv パッケージに含まれています (Voice from space / Software Archive / tserv version 0.2 (tserv.tar.gz))。

以下は、オリジナルの yatt の README からの引用です。

T-Code の漢字をカバーするなるべく小さな熟語集合、 というところがポイントです。 yatt.js は、この点を継承しつつ pubdic+ (少々内容が古いですが) からテキストを自動生成し eelll/JS 風のインターフェースで練習できるようにしました。 お試しください。
